# 目标受众、Families 政策与内容分级（R-08）

## 1. 目标受众

| 平台 | 选择 | 说明 |
|---|---|---|
| Google Play | 年龄组：`6–8`、`9–12`、`13–17`、`18+` | 学生 6–18 岁 + 家长/教师成年用户；含 13 岁以下 → 必须遵守 Families Policy |
| 华为 AppGallery | 3+ | 教育工具类，无广告、无付费、无社交 |

**儿童（<13 岁）账号规则**（与 `docs/privacy.md` §3 一致）：

- 注册须监护人阅读并同意《隐私政策》《用户协议》，账号标记 `is_child`；
- 至少绑定 1 名已确认监护人（`consent_at` 非空）后方可完整使用；
- 默认关闭社交、公开分享、排行榜与付费入口；
- 家长可设置每日时长、休息时段与青少年模式。

## 2. Google Play Families Policy 自查

| 要求 | 现状 | 证据 |
|---|---|---|
| 无广告；若含广告只能使用 Families 认证广告 SDK | 无任何广告 SDK | `docs/privacy.md` §5；`app/pubspec.yaml` 依赖清单 |
| 不收集与功能无关的个人信息 | 权限仅 `INTERNET` | AndroidManifest / 鸿蒙权限配置 |
| 不使用行为定向或再营销 | 无统计 SDK、无画像 | 同上 |
| 内容适龄：无暴力、性暗示、赌博、毒品、恐怖 | 仅学习内容 | 内容审核双人复核（P2-09）+ 举报下架（R-07） |
| 提供隐私政策且包含儿童信息处理说明 | 已具备 §3 未成年人专章 | `docs/privacy.md` §3 |
| 家长可在不提供敏感数据的前提下使用家长功能 | 家长绑定仅需手机号与孩子确认 | R-04 家长同意链路 |
| 不诱导儿童消费或分享 | 无内购、无分享入口 | 当前版本无付费 |
| 应用内购买需家长门 | 无内购（如后续上线会员须加家长门） | R-04 规划 |
| 教师审核（Teacher Approved，可选） | 暂不申请 | — |

> 若后续上线会员、推送或任何第三方 SDK，须重新评估 Families 合规并更新 Data Safety。

## 3. IARC 内容分级问卷（预填）

| 问卷项 | 选择 | 理由 |
|---|---|---|
| 暴力（卡通/写实/血腥） | 无 | 学习类内容 |
| 性 / 裸露 | 无 | — |
| 脏话 / 粗俗语言 | 无 | 题库经双人复核 |
| 受管制物质（烟酒毒品） | 无 | — |
| 赌博 / 模拟赌博 | 无 | — |
| 恐怖 / 惊吓 | 无 | — |
| 用户互动（聊天、UGC 分享、陌生人接触） | 无 | 无社交、无公开分享、无排行榜 |
| 位置共享 | 无 | 不申请定位权限 |
| 个人信息共享 | 有（账号注册收集手机号） | 仅用于登录与学情，不对外共享 |
| 数字购买 | 无 | 当前无内购 |
| 广告 | 无 | 无广告 SDK |

**预期分级**：ESRB `Everyone`、PEGI `3`、USK `0`、ClassInd `L`；华为 AppGallery 自评为 `3+`。
若平台因「收集手机号」判定为 `Everyone 10+` / `PEGI 7`，以平台实际下发为准，并在商店页面注明「需手机号注册」。
