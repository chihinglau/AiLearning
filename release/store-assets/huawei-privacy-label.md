# 华为 AppGallery 隐私标签填报（R-08）

> 华为应用市场要求在提审时填写「隐私标签」，声明收集的个人信息、权限、第三方 SDK 与数据存储地。
> 数据口径与 `docs/privacy.md`（`2026.11.06`）、`data-safety.md` 保持一致；任一项变更须三处同步。

## 1. 个人信息收集声明

| 信息类型 | 具体内容 | 使用目的 | 是否必需 | 是否共享 | 是否可删除 |
|---|---|---|---|---|---|
| 手机号 | 注册 / 登录 | 账号识别、安全验证 | 必需 | 否 | 注销后删除或匿名化 |
| 昵称 | 展示 | 账号资料 | 可选 | 否 | 是 |
| 学段 / 年级 / 角色 | 教材匹配、内容分级 | 学习功能 | 学生必需 | 否 | 是 |
| 教材绑定 | 教材、学期 | 学习路径 | 必需 | 否 | 是 |
| 学习记录 | 答题、错题、掌握度、测评、时长 | 学情报告与复习推荐 | 必需 | 否 | 是 |
| 家长绑定关系 | 绑定状态、确认时间 | 家长查看学情与管控 | 儿童必需 | 否 | 是 |
| 设备与日志 | 设备型号、系统版本、App 版本、崩溃摘要 | 兼容性适配、故障排查 | 必需 | 否 | 是 |
| IP 与操作日志 | 安全审计日志 | 安全风控、异常登录识别 | 必需 | 否 | 留存 6 个月–2 年 |

**明确不收集**：地理位置、通讯录、短信、通话记录、相机、麦克风、相册、生物识别信息、应用列表。

## 2. 权限清单

| 平台 | 权限 | 用途 |
|---|---|---|
| Android | `android.permission.INTERNET` | 访问学习服务（release 源集已显式声明） |
| HarmonyOS | `ohos.permission.INTERNET` | 同上 |

当前版本不申请任何危险权限（相机、定位、通讯录、存储写入等均为空）。

## 3. 第三方 SDK

| 类型 | 是否集成 | 说明 |
|---|---|---|
| 广告 SDK | 否 | 无广告 |
| 统计分析 / 埋点 SDK | 否 | 无行为分析 |
| 推送 SDK | 否 | 无营销推送 |
| 第三方登录 SDK | 否 | 手机号 + 密码登录 |
| 崩溃监控 SDK | 否（R-09 如接入需更新本标签） | 崩溃摘要通过服务端日志或用户反馈收集 |

## 4. 数据存储与安全

| 项 | 填写 |
|---|---|
| 存储地 | 中国大陆境内（不涉及出境） |
| 传输加密 | 全站 HTTPS/TLS |
| 密码存储 | 加盐哈希，不保存明文 |
| 敏感操作审计 | 100% 写审计日志（操作人、动作、时间、IP） |
| 留存期限 | 账号存续期；注销后 15 个工作日内删除或匿名化；审计日志 6 个月–2 年 |
| 数据导出 | 「我的 → 账号与安全 → 数据导出」 |
| 账号注销 | 「我的 → 账号与安全 → 注销账号」 |

## 5. 未成年人信息保护

| 项 | 填写 |
|---|---|
| 是否面向儿童 | 是（6–18 岁学生为主） |
| 监护人同意 | 是，未满 14 周岁须监护人阅读同意后注册（`is_child` + 绑定生效） |
| 家长管控 | 每日时长、休息时段、青少年模式；绑定/解除需双方确认 |
| 广告与营销 | 无广告；不向未成年人推送营销信息 |
| 社交与付费 | 儿童账号默认关闭社交、公开分享、排行榜与付费入口 |
| 举报与下架 | 「我的 → 内容举报」，24 小时内核实并下架争议内容 |

## 6. 与 Google Play / 隐私政策一致性核对

| 核对项 | 华为隐私标签 | Google Data Safety | 隐私政策 |
|---|---|---|---|
| 手机号 | 收集、不共享 | Phone number | §1.1 |
| 昵称 | 收集、可选 | Name（Optional） | §1.1 |
| 学段/年级 | 收集 | Other info | §1.1 |
| 学习记录 | 收集、不共享 | App interactions | §1.2 |
| 设备与日志 | 收集 | Diagnostics / Crash logs | §1.3 |
| 位置/通讯录/相机等 | 不收集 | 全部「否」 | §1.4 |
| 广告与统计 SDK | 无 | 无共享、无广告 | §5 |
| 注销与删除 | 15 个工作日 | 可请求删除 | §6.3 |

## 7. 提审前检查

- [ ] 隐私标签与 `docs/privacy.md` 逐项一致，无「未勾选但实际收集」项
- [ ] 权限清单仅 `INTERNET`，与安装包实际权限一致
- [ ] 第三方 SDK 为「无」；如 R-09 接入崩溃监控须更新标签并重新提审
- [ ] 隐私政策 URL、用户协议 URL 公网 HTTPS 可访问
- [ ] 儿童信息保护与家长管控可在真机演示（R-03/R-04 已验收）
