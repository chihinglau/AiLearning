## 3. 提交流程（CPCC 线上）

1. 注册并登录中国版权保护中心线上系统，完成实名认证（个人或企业）。
2. 新建软件著作权登记申请，按 `metadata.json` 填写软件信息与开发信息。
3. 上传 `source-code.docx` 与 `user-manual.docx`（PDF 或 Word，按系统要求）。
4. 核对材料：源程序页眉页脚完整、无第三方版权声明、无真实学生信息；说明书内容与软件功能一致。
5. 提交后在线缴费，选择加急服务（以系统当期受理周期为准）。
6. 受理后记录受理号；取得登记证书后填写 `registration.txt` 并归档，作为 R-06 应用备案的资质附件。

## 4. 注意事项

- 源程序须为申请日前完成的代码，提交内容不得包含开源协议头中与著作权归属冲突的声明。
- 软著名称“深爱学学习辅助软件”须与商店展示名称、后续 APP 备案信息保持一致，避免 R-06 返工。
- 著作权人为个人时，登记证书上的姓名须与身份证一致；为企业时须与营业执照一致。
- 登记号取得后，在 App「关于」页与商店资质处按需展示。
- 本目录材料含申请信息，提交前请确认不包含手机号、真实学生姓名等个人信息（当前生成为通用文案，无个人信息）。
