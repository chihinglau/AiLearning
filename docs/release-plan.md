## 1. 结论速览

| 维度 | 结论 |
|---|---|
| **产品定位** | 面向深圳 K12 的**学习辅助工具**（同步练习、错题本、知识点讲解、测评与学情报告），**不是**学科培训机构、不售课、不直播 |
| **首发渠道** | 华为 AppGallery（Android APK + HarmonyOS HAP 双形态）+ 小米应用商店；Google Play 视海外需求并行 |
| **首发形态** | 免费基础功能 + 可选会员订阅（华为 IAP / 小米 IAP / Play Billing）；**不接广告**（未成年人优先） |
| **上架前必须补齐** | ① 软著 ② APP 备案 ③ 隐私政策公网 HTTPS URL ④ App 内首启同意 + 隐私/协议/注销入口 ⑤ 正式签名（禁止 debug 回退）⑥ 后端生产化部署 ⑦ 内容版权合规 ⑧ 商店素材与合规表单 |
| **个人主体可行性** | 软著、APP 备案、华为/小米/Play 个人实名均可办；但**未成年人数据 + 教育类目**审核严格，正式运营建议个体户/公司 |
| **最大风险** | 未成年人个人信息违规（PIPL/儿童规定）与教材/题库版权，其次是"双减"类目误判 |
| **核心对策** | 数据最小化 + 监护同意链路 + 原创/授权内容台账 + 工具定位表述 + 全量审计日志 |
| **建议路径** | 个人名义内测与灰度 → 个体户/公司主体正式上架与收款 → 学校 B 端另走合作（不进应用商店） |

## 3. 上架前必须补齐的缺口

### 缺口 1：正式签名与构建纪律（**阻断所有商店**）

**现状问题**

- [build.gradle.kts](file:///d:/ai/prj/trae/HuaWei/AiLearning/app/android/app/build.gradle.kts#L46-L50) 中 release 签名配置缺失时回退 `debug`：
  ```kotlin
  signingConfig = signingConfigs.findByName("release") ?: signingConfigs.getByName("debug")
  ```
  一旦漏配 `keystore.properties`，会静默产出 **debug 签名的 release 包**，导致备案信息不符、商店拒审或后续无法升级。
- 尚未生成 release keystore（`keystore.properties`、`.tools/signing/ailearning.jks` 均不存在）。
- 双端 versionCode 不一致（Android `1` / HarmonyOS `1000000`）。

**技术待办**

- [ ] 执行 `scripts/make-release-keystore.ps1` 生成 keystore，**立即备份到密码管理器/密钥库**（丢失即无法升级）
- [ ] 修改 `build.gradle.kts`：release 构建时若缺 `keystore.properties` 直接 `throw GradleException`，**禁止回退 debug**
- [ ] 统一发版号规则并写入 `skills.md`：建议 `versionCode = major*10000 + minor*100 + patch*10 + build`（如 `1.0.0+1 → 10001`），Android 与 HarmonyOS 取同值
- [ ] 导出签名 MD5 / SHA-256 记录在案（备案用）
- [ ] 每次 release 构建后执行 `apksigner verify --print-certs`，确认非 debug 证书
- [ ] HarmonyOS：在 DevEco/AGC 生成正式签名证书与 Profile，替换当前自动签名；HAP 与 Android 包名保持同名

**验收标准**：空环境执行构建脚本，缺签名即失败；有签名时 `apksigner` 输出 CN=AiLearning 且与备案 MD5 一致；双端 versionCode 相等。

### 缺口 2：隐私政策公网 URL + App 内法务页与首启同意（**阻断备案与提审**）

**现状**

- `docs/privacy.md` 已完成 K12 版源稿，但**没有公网可访问地址**，App 内也没有任何法务页面。
- 无首次启动同意弹窗（ConsentGate），无版本变更重新同意机制。

**技术待办**

- [ ] 部署公网隐私政策页（建议后端新增 `GET /legal/privacy` 与 `/legal/terms`，渲染 Markdown 为 HTML；或静态托管）
  - 必须 **HTTPS**、无需登录、PC 与手机均可访问
  - 地址写入后端配置并在 App「我的 → 关于与支持」展示（云端下发，避免改代码发版）
- [ ] 域名 ICP 备案（若自建站点）→ 获取公网 URL（ICP 备案 ≠ APP 备案，见缺口 4）
- [ ] App 内新增「隐私政策」「用户协议」「账号注销」「联系我们」入口（我的页）
- [ ] 实现首启同意弹窗：
  - 展示《隐私政策》《用户协议》摘要 + 链接，**主动勾选**后进入
  - 拒绝则退出应用，不采集任何信息
  - 儿童账号（<14 岁）注册时增加**监护人确认**步骤
  - 记录同意时间与版本号；政策版本升高自动重新征求同意
- [ ] 隐私政策版本号与 App 版本解耦（建议 `2026.11.06`），后台可更新

**验收标准**：公网 URL 可直接打开且内容与 App 内一致；卸载重装首次启动必须同意；拒绝后无网络请求；版本升级触发重新同意。

### 缺口 3：后端生产化部署（**阻断真实用户使用**）

**现状**：仅本地开发形态（SQLite、HTTP、`10.0.2.2`/局域网 IP），无域名、无 HTTPS、无备份。

**技术待办**

- [ ] 生产环境：云服务器 + 域名 + HTTPS 证书（TLS 1.2+）
- [ ] 数据库切 PostgreSQL，`alembic upgrade head` + `seed.py` 幂等初始化
- [ ] 密钥管理：JWT 密钥、数据库口令走环境变量/密钥管理，禁止入库
- [ ] 安全基线：CORS 白名单、登录/注册限流、请求体大小限制、错误信息脱敏、最小权限数据库账号
- [ ] 运维基线：每日备份 + 恢复演练、日志留存（审计日志 ≥6 个月）、健康检查与告警
- [ ] App 生产构建固定 `--dart-define=API_BASE_URL=https://<域名>`；Android 配置 `network_security_config` **禁止明文流量**
- [ ] 合规：若使用云服务商，签署数据处理协议（受托处理）

**验收标准**：公网 HTTPS 可访问 `/health`；弱网/断网有友好提示；明文 HTTP 请求被客户端拒绝；备份可恢复。

### 缺口 4：APP 备案（中国大陆强制）

**要点**

- 自 2023-09 起，未完成 **APP 备案** 的应用不得在国内分发平台上架。
- 个人主体可办：身份证、手机号、**App 包名**、**签名证书 MD5**、**隐私政策公网 URL**、App 基本信息、SDK 列表（本项目当前为空）。
- 路径：先完成应用商店开发者实名 → 在商店侧发起 App 备案（由分发平台代送审）；若自建后端站点，还需要域名 **ICP 备案**。
- 变更：包名 / 签名 / 主体 / 应用名称变更需做**变更备案**。

**行动**

- [ ] 导出 release 签名 MD5/SHA-256（附录 A）
- [ ] 确认隐私政策公网 URL 可访问（缺口 2）
- [ ] 华为、 小米各提交一次 App 备案
- [ ] 备案号回填后端配置并在 App「关于」页展示
- [ ] **包名 `com.ailearning.ai_learning` 与签名终身不变**，写入 `skills.md` 与发布检查表

### 缺口 5：软件著作权证书（国内商店硬性资质）

**要点**

- 个人主体可申请，权利人为申请人本人；受理机构：中国版权保护中心（CPCC）。
- 材料：源程序前后各 30 页（每页 50 行，去空行/注释）、操作说明书（约 10 页，含截图）、身份证明。
- 周期：普通件约 30–60 个工作日，加急约 10–30 个工作日（以 CPCC 当期公告为准）。
- 软件名称建议：**"深爱学学习辅助软件"**（与商店展示名"深爱学"保持一致或提供说明，避免审核质疑）。

**行动**

- [ ] 整理源码 60 页：`app/lib`（Dart 业务层）+ `backend/app`（API/模型），避免大段空白
- [ ] 编写操作说明书：注册登录 → 选年级/教材 → 练习 → 错题本 → 学情报告 → 家长绑定
- [ ] CPCC 线上提交（勾选加急）
- [ ] 记录软著登记号，国内商店提审统一填写

> ⚠️ 软著是**国内上架路径上周期最长**的一项，必须在 P0 第 1 天启动；Google Play 不依赖软著。

### 缺口 6：内容版权与教育合规（**本项目特有，风险最高**）

**风险点**

| 风险 | 说明 | 对策 |
|---|---|---|
| 教材版权 | 人教版 / 粤教版 / 牛津深圳版等名称与内容受版权保护 | 仅以"适配/参考"描述版本；**不得**使用教材封面、内页扫描、官方 Logo；不宣称"官方/指定" |
| 题库版权 | 真题、教辅题目有著作权 | 题目必须原创或取得书面授权；建立**题源台账**（来源/授权凭证/录入人/审核人） |
| 双减类目 | 被误判为学科培训机构 | 定位"学习辅助工具"；**不售课、不直播、不一对一、不承诺提分** |
| 未成年人内容 | 题目与解析需适龄、无不良信息 | 内容审核流程 + 举报入口 + 下架机制 |
| AI 讲解（P2） | 生成内容不可控 | 上线前完成生成式 AI 合规评估、内容安全过滤、人工抽检 |

**行动**

- [ ] 建立《内容来源与授权台账》（CT 负责），逐条记录题目/知识点来源
- [ ] 商店描述与 App 内加入免责声明：内容仅供学习参考，与教材出版方无关
- [ ] 删除任何"官方教材同步""名师""提分""押题"类表述
- [ ] 家长/教师举报入口与 24h 下架流程

## 4. 渠道矩阵

| 渠道 | 主体要求 | 硬性资质 | 费用 | 个人可行性 | 优先级 |
|---|---|---|---|---|---|
| **华为 AppGallery（Android）** | 个人 / 企业 | 实名 + 软著 + APP 备案 + 隐私 URL | 免费 | ✅ 高 | ⭐⭐⭐ |
| **华为 AppGallery（HarmonyOS HAP）** | 个人 / 企业 | 同上 + AGC 签名证书/Profile | 免费 | ✅ 高 | ⭐⭐⭐（差异化优势） |
| **小米应用商店** | 个人 / 企业 | 实名 + 软著 + 备案 | 免费 | ✅ 高 | ⭐⭐⭐ |
| **Google Play** | 个人 / 企业 | Play 账号 + AAB + Data Safety + 隐私 URL；含儿童则需 Families 合规 | **$25 一次性** | 🟡 中（个人新账号需 12 人×14 天封闭测试） | ⭐⭐ |
| **酷安** | 个人 / 企业 | 软著 | 免费 | ✅ 高（量级较小） | ⭐⭐ |
| **OPPO 软件商店** | 个人 / 企业 | 软著 + 备案 | 免费 | 🟡 中（教育类审核较严） | ⭐⭐ |
| **vivo 应用商店** | 个人 / 企业 | 软著 + 备案 | 免费 | 🟡 中 | ⭐⭐ |
| **应用宝（腾讯）** | 倾向企业 | 企业资质 + 软著 + 备案 | 免费 | ❌ 低 | ⭐ |
| **GitHub Releases / 内测** | 无 | 无 | 免费 | ✅ | ⭐（仅内部测试，不作正式分发） |

**渠道策略**

1. **首发**：华为（Android + HarmonyOS）+ 小米，覆盖深圳家长主流机型与鸿蒙生态，形成"双端原生"卖点。
2. **并行**：Google Play（面向有海外/出境需求的家庭，注意 Families 政策）。
3. **二线补充**：OPPO / vivo / 酷安。
4. **暂缓**：应用宝（个人基本不可行）。

## 5. 个人名义 vs 个体户 vs 公司名义

### 5.1 逐项对比

| 维度 | 个人开发者 | 个体户 | 公司名义 |
|---|---|---|---|

| **主体变更成本** | — | 中 | 需重新备案 + 软著变更 |

### 5.2 决策建议（三阶段）

**阶段一：个人名义（内测与灰度）**
- 目标：完成软著/备案链路验证、上华为与小米灰度、收集 100–500 名深圳家庭反馈。
- 限制：不开放付费；不接广告；儿童功能仅对已同意监护人开放。

**阶段二：个体户（开始收费前）**
- 解决开票、收款与部分商店主体要求；成本低、注册快。
- 完成软著/备案的主体一致性核对。

**阶段三：有限公司（规模运营 / 学校合作 / 融资）**
- 承接学校 B 端合作、处理协议与等保/数据合规要求；
- 商标、软著、备案迁移至公司；
- 可引入等保测评与个人信息保护合规审计。

> ⚠️ 主体迁移需重新备案与软著变更，**一次规划到位**，避免反复切换。
