## 第一部分：分学段学习科学总框架

行业标杆（学而思/猿辅导/作业帮/科大讯飞 AI 学习机/洋葱学院/Quizlet/Khan Academy/Anki）的共性方法论可归纳为五条学习科学支柱，深爱学所有学科功能均围绕它们设计：

| 支柱 | 理论来源 | 产品形态 | App 落地 |
|---|---|---|---|
| **掌握学习**（Mastery Learning） | Benjamin Bloom | 学—练—测—补闭环，80% 正确率才进阶 | 知识点掌握度 0-100、进阶门控、薄弱点重练 |
| **间隔重复**（Spaced Repetition） | Ebbinghaus 遗忘曲线 / SM-2（Anki） | 错题按 1/3/7/15 天复现 | 错题本调度器 `next_review_at` |
| **检索练习**（Retrieval Practice） | Roediger & Karpicke | 低利害小测、填空/默写优先于选择 | 多题型（单选/多选/判断/填空），题型权重 |
| **脚手架讲解**（Scaffolding） | Vygotsky 最近发展区 | 分步解析、提示、变式题 | 提交后展示解析 + 同知识点变式推荐 |
| **学情反馈**（Feedback Loop） | Hattie 反馈效应 | 错因标签、知识图谱热力图 | 错因标注 + 掌握度图谱 + 周报 |

**分学段差异化原则**：

- **小学（1-6 年级）**：兴趣与习惯优先。游戏化激励、短时高频（单次 10-15 分钟）、家长参与、大字号少文字、语音题干（防识字门槛）；重基础运算与字词的**自动化**（automaticity）。
- **初中（7-9 年级）**：方法与体系优先。知识图谱前置依赖显性化、解题步骤规范、错题归因、中考真题难度爬坡；物理（8 年级起）/化学（9 年级起）重实验情境。
- **高中（10-12 年级）**：自主与应试优先。选科走班适配、高频考法模型、综合题拆解、限时套卷、薄弱点个性化冲刺；错题本支持"题型/考法"维度归纳。

## 第二部分：分学科辅导方法详案

### 2.1 语文（小学→高中）

**能力结构**：识字写字 / 阅读 / 写作 / 积累（古诗文、文常）/ 语言运用。

- **小学**：
  - 低段（1-2）：拼音（声母/韵母/整体认读/声调）、生字（笔顺/偏旁/多音字）——采用"字源动画+跟读+听写"行业做法（悟空识字、洪恩识字）；App 用看拼音写词语、选字填空、笔顺判断题。
  - 中段（3-4）：段落理解、修改病句、关联词；阅读从"提取信息"到"推断"；看图写话。
  - 高段（5-6）：篇章概括、修辞（比喻/拟人/排比）、文言文启蒙（小古文）、记叙文写作六要素。
  - 方法：**晨诵暮省**（每日 5 分钟背诵打卡：古诗/日积月累）、**字词句篇**四级螺旋。
- **初中**：现代文阅读题型化（赏析句子=手法+内容+情感三段式）、文言文实词虚词 120/15 个清单、中考作文素材库与结构模板（横式/纵式）。
- **高中**：群文阅读、整本书阅读（《乡土中国》《红楼梦》高考要求）、议论文论证方法、文言文 120 实词在语境中推断、古诗词鉴赏术语体系（意象-意境-情感）。
- **App 功能**：背诵打卡（间隔复习调度）、阅读理解分题型专项、作文采用"AI 辅批 + 好词好句积累卡"（M3）。

### 2.2 数学（小学→高中）

**能力结构**：数与运算 / 几何与空间 / 应用建模 / 逻辑推理 / 统计概率。

- **小学**：
  - 计算自动化是第一性原理（猿辅导口算、小猿口算的核心）——10/20/100 以内进退位、乘法口诀、小数分数四则；每日 5 分钟口算打卡，限时造成就感。
  - 应用题用"画线段图/示意图"脚手架；错题按错因分类（审题/计算/概念/方法）。
  - 几何重操作（长方体展开、平移旋转），后续配动画讲解（M3）。
- **初中**：有理数→代数式→方程→函数的抽象爬坡（七下-八上是分化点，需前置依赖门控）；几何证明"三步书写"（∵∴依据）；函数图象数形结合；错题归因到知识点（如"去括号变号"）。
- **高中**：函数主线（性质→基本初等函数→导数）、向量/立几的空间想象、解析几何计算量、概率统计；采用"题型模型卡"（如导数隐零点、圆锥曲线设点设线）。
- **App 功能（本轮）**：确定性题目生成器（按年级生成加减乘除/方程，数字随机可复现）、难度 1-5 随掌握度自适应（掌握度 <60 出难度 1-2，60-85 出 3，>85 出 4-5）、填空题要求精确答案。

### 2.3 英语（小学→高中）

**能力结构**：语音 / 词汇 / 语法 / 听 / 说 / 读 / 写。深圳小学使用**牛津深圳版（Shanghai Oxford）**，是深圳本地化重点。

- **小学**：自然拼读（phonics）+ 高频词（sight words）；词汇用图片-声音-情境多模态（多邻国/Quizlet 模式）；每日 5 词间隔复习；句型模仿跟读。
- **初中**：考纲 1600 词 + 300 短语；语法体系（时态/从句/被动）；完形与阅读限时训练；听说考试 15 分（深圳中考特色）——需模仿朗读、信息转述、口头作文（M3 接语音评测）。
- **高中**：3500 词词根词缀、长难句分析、读后续写/概要写作（新高考）、外刊阅读。
- **App 功能（本轮）**：词汇题（英选中/中选英/拼写填空）、语法单选、判断题；（M3）TTS 题干 + 语音评测接华为 ML Kit 语音。

### 2.4 物理（初中 8 年级起 / 高中）

- **初中**：声、光、热、力、电；重"生活现象→物理模型→实验探究"。选择题考概念辨析，填空题考公式直接应用，实验题考变量控制。
- **高中**：运动学→力学→能量→电磁的强前置链（挂科常因三角/矢量数学薄弱，跨学科依赖）；题型模型（板块、传送带、电磁复合场）。
- **方法**：公式卡（适用条件+单位+变形）、实验题模板（目的/原理/器材/步骤/数据/误差）、跨学科前置检查（数学三角函数掌握度）。
- **App 功能（本轮）**：知识点前置依赖门控、公式填空、情境判断；（M3）受力分析/电路图作图题。

### 2.5 化学（初中 9 年级起 / 高中）

- **初中**：启蒙期重兴趣与规范——化学用语（元素符号/化合价/化学式/方程式"四层分化"）、气体制备实验、酸碱盐推断。
- **高中**：物质的量（mol）计算是第一道坎、氧化还原/离子反应双线、元素周期律、有机化学官能团转化、反应原理（速率/平衡/电化学）。
- **方法**：方程式卡按反应类型间隔默写、"宏-微-符"三重表征（Johnstone 三角）、实验装置与操作规范。
- **App 功能（本轮）**：方程式/元素符号填空（答案容忍空格、大小写规范提示）、概念判断；（M3）配平交互题。

### 2.6 生物（初中 / 高中）

- 初中偏科普记忆（生物体结构、生态系统、健康），用图注填空；高中重机制（光合/呼吸过程、遗传规律、稳态调节）与实验设计。
- App：图结构标签题（M3）、概念辨析判断、过程排序题（M3）。

### 2.7 历史 / 地理 / 政治（道德与法治）

- **历史**：时间轴（timeline）是元认知工具——大事年表间隔重现；材料题"材料+所学"两段作答。高中用唯物史观（生产力/阶级）分析。
- **地理**：地图是第二语言（经纬网/气候图/地形图）；高中自然地理重因果链（大气环流→气候→植被），人文地理重模板（区位因素）。
- **政治/道法**：时政结合（App 每周更新时政卡片，M4）；主观题"材料-教材观点-分析"三段论。
- **App 功能（本轮）**：时间/事件填空、概念判断、因果选择题；（M4）地图题与时政卡。

### 2.8 深圳本地化要点（差异化竞争力）

1. **教材版本**：英语牛津深圳版（1-9 年级）、数学北师大版（深圳初中常用）/人教版、物理人教版、化学人教版。
2. **中考特色**：英语听说 15 分机考（App 专项，M3）、道法+历史合卷、生物地理初二会考。
3. **新高考**：3+1+2 选科（广东），App 高中学情按选科科目配置（M5）。
4. **校历与考点**：对接深圳校历（22 周/学期）、期中期末区间，章节进度按学期推送（M3）。

## 第三部分：M2 软件设计

### 3.1 本轮实施范围（已冻结）

| 范围 | 内容 |
|---|---|
| 数据模型 | 题目显式关联知识点；新增错题本（含间隔复习调度字段） |
| 学情引擎 | 掌握度 EMA 更新；SM-2 Lite 错题复习调度；自适应出题（掌握度→难度配比） |
| API | 知识树、知识点掌握度、自适应练习、错题本 CRUD、今日复习、学情总览 |
| 种子数据 | 全学段 9 学科 63 本教材元数据；小学 1-3 年级语数英完整章节/知识点/多题型题目（确定性生成）；4-12 年级各学科样章占位 |
| 客户端 | 三 Tab 架构（学习/错题本/我的）；章节→知识点页（掌握度环）；通用多题型答题页（单选/多选/判断/填空）；错题复习；学情总览 |
| 不做 | AI 生成/语音/作图题/套卷/家长端（M3-M5） |

### 3.2 数据模型变更

```
questions 新增列：
  knowledge_point_id  BIGINT NULL FK(knowledge_points.id) INDEX

新增表 wrong_questions（错题本，一生一错一行，聚合多次作答）：
  id, user_id, question_id（UNIQUE(user_id, question_id)）
  wrong_count, correct_streak          -- 错误次数 / 连续答对次数
  status: active/mastered             -- 未消灭 / 已掌握
  ease_factor(默认2.5), interval_days, reps, lapses   -- SM-2 字段
  next_review_at, last_wrong_at
  wrong_reason(审题/计算/概念/方法/粗心/其他)
```

掌握度沿用 `mastery_scores(score 0-100, confidence)`，由提交事件实时更新。

### 3.3 学情算法（确定性、可测试）

**① 掌握度 EMA（指数滑动平均）**

```
每次作答后（按题目关联 KP 聚合）：
  p = 1.0 答对 / 0.0 答错
  score_new = 0.6 * p * 100 + 0.4 * score_old     # 初始 0
  confidence_new = min(confidence_old + 1, 20)
连续 3 次答对（correct_streak>=3 且最近一次难度>=3）→ status=mastered
```

**② 自适应出题难度配比**

| 掌握度 | 难度分布（1-5） |
|---|---|
| 0-39（薄弱） | 70% 难度1-2，30% 难度3 |
| 40-69（巩固） | 20% 难度2，60% 难度3，20% 难度4 |
| 70-84（熟练） | 30% 难度3，50% 难度4，20% 难度5 |
| 85-100（精通） | 40% 难度4，60% 难度5 |

出题优先插入 `wrong_questions` 中 `next_review_at <= now` 的到期错题（30% 题量），其余按难度配比从该 KP 抽取。

**③ SM-2 Lite 间隔调度（错题复活机制）**

- 首次答错：interval=1 天，ease=2.5
- 复习答对：interval = round(interval × ease)，序列约 1→3→7→16…；连续答对 3 次且最近题目难度≥3 → mastered
- 复习答错：correct_streak 归零，lapses+1，interval=1，ease=max(1.3, ease-0.2)

### 3.4 API 设计（本轮新增）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/public/knowledge-tree?subject&grade` | 树形知识结构（章→知识点，附个人掌握度） |
| GET | `/api/learn/mastery?subject` | KP→{score,confidence} 映射 |
| POST | `/api/learn/start` | 自适应组卷（kp_id 或 chapter_id，含到期错题） |
| POST | `/api/learn/submit` | 提交：判题+写记录+更新掌握度+错题本/调度 |
| GET | `/api/learn/wrong-questions` | 错题本列表（可按 status/subject 过滤） |
| POST | `/api/learn/wrong-questions/{id}/reason` | 标注错因 |
| GET | `/api/learn/review/today` | 今日到期复习题 |
| GET | `/api/learn/stats` | 学情总览（连续天数/做题数/正确率/待复习/薄弱 KP Top3） |

旧 `/api/practice/*` 保留兼容。

### 3.6 后续路线衔接

- **M2 第二批**：4-12 年级完整内容入库、口算/听写打卡、知识点讲解卡。
- **M3**：AI 解析与变式题、英语 TTS+听说评测（华为 ML Kit）、物理作图题、家长端报表。
- **M4-M5**：套卷/考试、选科配置、时政卡、激励体系（合规：不可诱导消费）。
