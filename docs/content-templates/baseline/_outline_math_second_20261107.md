# 数学 下册教材大纲基线（北师大版，1-8 年级）

## 一、口径

- **教材完整性第一优先**：每日产出的 `section` 必须是本文件列出的单元名、节名之一，越界即视为「超出教材范围」。
- **现行册次为准**：1-3、7-8 年级用 2025/2026 春版新教材；4-6 年级 2026 春仍为 2013 版册次（新教材 2026 秋才推到四、五年级）。
- **颗粒度**：1-2、7-8 级到节；3-6 年级只到单元（侧栏无节名），按单元推进，不要自拟节名。
- **版权边界**：只记录目录标题（事实性短名），不含例题、习题原文。

## 四、使用规则

1. 按表格从上到下推进，做过的单元/节在台账登记，不回头重做。
2. `section` 写本文件原名，不加书名号；「整理与复习」「总复习」「数学好玩」也算合法节点。
3. 行内 ` / ` 分隔的每个名称都可单独作为一天任务。
4. 3-6 年级只有单元名：按单元推进、单元内自选知识点，**不要自拟节名**。
