# 数学 上册教材大纲基线（北师大版，1-8 年级）

## 一、口径

- **教材完整性第一优先**：每日产出的 `section` 必须是本文件列出的单元名、节名之一，越界即视为「超出教材范围」。
- **以现行新教材为准**：按 2024/2025/2026 秋版逐年推行后的现行册次取目录，不做新旧过渡映射。
- **版本**：北师大版（小学 1-6 / 初中 7-8）。
- **版权边界**：只记录目录标题（事实性短名），不含例题、习题原文；每日题目须自拟题干。
- **一门课一天一节**：节内知识点 3-6 个、题 18-28 道；一节内容多可拆两天，不跨节跳做。

## 十一、使用规则

1. 按表格从上到下推进，做过的节在台账登记，不回头重做。
2. `section` 写本文件原名，不加书名号；「整理与复习」「总复习」也算合法节。
3. 行内 ` / ` 分隔的每个名称都可单独作为一天任务。
4. 1-3 年级当前只有单元名：按单元推进、单元内自选知识点，**不要自拟节名**；待学科网对应专辑补齐后再切课时级。
