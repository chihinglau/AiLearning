## 检查口径

硬问题（计入 `papers_with_issues`）：
- `DUP` 同一道题在一卷里出现多次
- `ORPHAN` 试卷引用的题号已不在题库（学生打开即缺题）
- `EMPTY_STEM` 题干为空
- `EMPTY_ANSWER` 答案为空
- `GRADE_MISMATCH` 题的年级与卷的年级不一致
- `SUBJECT_MISMATCH` 题的学科与卷的学科不一致
- `AUDIO_MISSING` 听力题的音频文件未就绪

软提示（不计入缺陷）：
- `LEAK_INFO` 由题型决定、无法消除的情况，报告里保留原样供抽查：
  - 答案取自短文原文（阅读理解必然）
  - 答案落在候选括号内（「填『是』或『否』」这类提示题型）
  - 单字答案只是题干里更长词的组成部分（「语」出现在「成语」里）
- `LEAK_WARN` 其它提示（例如单字答案在题干里独立成词出现），需教研判是否改题干
- `LEAK_BLOCK` 答案成段出现在题干：需改写题干（本报告中已清零）
