# 导入说明（给另一台主机 / 手机用）

本目录是 9 条「每日教研」定时任务的完整导出，按「先建目录、再建任务、最后校验」三步走。

## 目录内容

| 文件 | 用途 |
|---|---|
| `01-九条任务全文可复制.md` | 9 条任务的标题、cron、运行环境与 **query 全文**（代码块内可直接整段复制） |
| `00-导入说明.md` | 本文件 |
| `_daily-task-instruction.md` | query 里引用的执行指令文件，必须放到目标机的同路径位置 |
| `_validate_daily.py` | 逐年级自检脚本，query 里每条都要调用它。**本包内这份 = 内容根现行版的逐字节副本**（sha256 相同），换机后直接放到目标机内容根即可；它必须与 `baseline\`、`_import-manifest.json` 同级才完整生效（详见文末「校验器版本」） |
| `_tmp_ledger2.py` | 台账 / 运行日志生成脚本（可选，用于事后补台账） |

## 步骤一：搬目录（必须做，否则任务一定失败）

目标机需要这份结构，路径建议保持一致：

```
<内容根>\
├─ _daily-task-instruction.md
├─ _validate_daily.py
├─ baseline\                     ← 大纲与章节、知识点基线，缺了自检会全量报「不在大纲内」
├─ daily\{subject}\g{n}\         ← 产物落盘处（可空目录启动）
├─ ledger\{subject}\g{n}.md      ← 台账，决定「下一节」从哪开始，从旧机整份拷过来
└─ logs\{subject}_first.md       ← 运行日志与断点记录
```

同时目标机需要有 Python 环境（原本用的是 `backend\.venv\Scripts\python.exe`）。

> 只拷 JSON 不拷 `ledger\` 的后果：每册都会被当成「第一节没跑过」，从第一课重来。

## 步骤二：建 9 条定时任务

在目标机的任务中心「新建定时任务」，每条按下表填，**运行环境选「本地电脑」**：

| 标题 | 类型 | 表达式 |
|---|---|---|
| 数学1-8上每日教研 | cron | `0 2,12,22 * * *` |
| 语文1-9上每日教研 | cron | `5 2,12,22 * * *` |
| 英语1-9上每日教研 | cron | `10 2,12,22 * * *` |
| 道法1-9上每日教研 | cron | `15 2,12,22 * * *` |
| 物理8-9上每日教研 | cron | `20 2,12,22 * * *` |
| 化学9上每日教研 | cron | `25 2,12,22 * * *` |
| 生物7-8上每日教研 | cron | `30 2,12,22 * * *` |
| 历史7-9上每日教研 | cron | `35 2,12,22 * * *` |
| 地理7-8上每日教研 | cron | `40 2,12,22 * * *` |

query 一律从 `01-九条任务全文可复制.md` 里对应标题的代码块整段粘贴。时区为 `Asia/Shanghai`，错峰 5 分钟是为了避免 9 个任务同时抢锁和抢模型额度。

query 里出现的绝对路径共两类，若目标机不是 `D:\ai\prj\trae\HuaWei\AiLearning\docs\content-templates`，用一次「全部替换」即可：

## 手机上怎么用

- 看 / 复制 query：直接打开 `01-九条任务全文可复制.md`。
- 真正要「跑」必须在有这份目录和 Python 的电脑上，手机端只能建任务、不能执行本地脚本。所以手机上适合做「改 query、看进度汇报」，执行仍落在电脑。

## 首次跑完请核对这三件事

1. `daily\{subject}\g{n}\` 下是否出现当天日期的新文件
2. `logs\{subject}_first.md` 是否有当天批次记录（含每册知识点数与题量）
3. `logs\_daily-lock_{subject}_first.txt` 跑完应被删除；若残留超过 30 分钟会在下一班被自动清掉

## 校验器版本（换机前先读这段）

- 本包里的 `_validate_daily.py` 是 **2026-11-08 22:0x 现行版**的逐字节副本（`39027 B / 832 行`，
  sha256 `c9d80e7cc6404c84…`）。它已支持三列 manifest 三态（`unchanged / meta_only / changed`）
  与 `_legacy` 标记；换机后请以**目标机内容根**下的这一份为准，不要另找旧副本。
- 历史那份「单列 sha、不认 `_legacy`」的冻结快照已挪到内容根 `_archive\_validate_daily.frozen-20261108-2214.py`
  留痕，**不要使用**。
- 校验器按自己所在目录找 `baseline\` 与 `_import-manifest.json`：直接把 `exports\automation_20261108\`
  里的副本原地运行会丢掉大纲范围校验和「已入库」三态判定，所以必须**拷到内容根再跑**。

## 已知坑（换机时踩过）

- **章节名必须与大纲文件原串一致**：曾把「第一单元走进社会生活」按口语加了空格，自检直接判「不在本册大纲内」。换机后不要「顺手美化」章节名。
- **数值型填空会触发「无算式」提醒**：如「3.5 m = 350 cm」，只提醒不阻断。规避办法是让解析写出完整算式，或改成非数值问法。
