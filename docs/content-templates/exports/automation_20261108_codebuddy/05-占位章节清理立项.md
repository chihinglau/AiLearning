## 3. 目标与非目标

### 目标

- G1 教材真实章节的 `order_index` 与官方骨架**完全一致**，同册内**零撞号**。
- G2 能判定归属的旧样章：题目**迁移**到教材真实章节后删除旧章（内容零丢失）。
- G3 不能判定归属的旧样章：**阶段 1 口径**是题目原地保留 + 章节标 `is_placeholder=1` + 序沉底，
  app 端按 `is_placeholder` 过滤；**阶段 4（用户授权「旧版数据删掉」）后改为整章删除**——见 §5 阶段 4。
- G4 全过程**可回滚**（备份 + `db_op_*.json` 留痕 + 幂等脚本）。
- G5 旧版数据**不能复活**：导入层把旧版数据章名列入 `discard`，重导旧 JSON 一律丢弃。

### 非目标（明确不做）

- 不改章节**名字**（改名会让「按名 upsert 重建」的导入路径再生成旧章，得不偿失）。
- 不改知识点（`knowledge_points`）树与名字——树本身健康，知识点名带「（要点）」后缀是
  2026-11-07 去重迁移的既定产物，属另一件事。
- **不把旧主题硬塞进不对应的教材单元**（如「小数除法」在北师大五上目录里没有对应单元）。
- 阶段 1/3 口径下**不删除任何题目**（所有迁移都只改 `questions.chapter_id`）；
  **阶段 4 例外**：用户明确指示「旧版数据删掉」，教材目录上不存在的那 24 章连同其 130 题、
  61 个随之变空的独占知识点**整块删除**（该决策已单独留痕、可回滚）。
- 不重跑 11-07 批次的教研出题（11-07 已定为 legacy，见 `tasks.json` 的 `legacy_batches`）。

## 4. 判定规则

| 规则 | 定义 | 采纳条件 |
|---|---|---|
| **R-A** 核心名匹配 | 旧样章名剥掉「第N单元/第N章/Unit N/第N课」前缀后，与该册某个官方章剥同样前缀后的名字**完全相同** | 在该册官方章中**唯一命中**才采纳 |
| **R-B** 显式映射 | 旧样章与官方章之间存在可写清依据的一一对应（单元序号一致 / 主题关键词在官方章名中唯一命中 / 题目内容自证） | 逐条写明依据，且**依据可被复核**（来自官方骨架名、章节序号、题目内容或大纲节名） |
| **R-C** 保留待确认 → **阶段 4 改为整章删除** | 新教材目录里没有对应单元，或归属存在歧义 | 阶段 1/3 口径：**不硬归类**（原地保留 + 标 `is_placeholder=1` + 写待确认清单）；**阶段 4（用户指示「旧版数据删掉」）**：整章删除，不再等业务确认 |

R-C 的最终处置由用户拍板：2026-11-08 指示「旧版数据删掉」→ 教材目录上没有的内容不留。

### 5.x.2 第十一轮评审（2026-11-08 22:0x · manifest 地基 + 只读巡检 + 空态）

第十一轮评审认定上一轮落地到位，但指出**唯一有分量的隐患在 `_import-manifest.json`**：
为让 legacy 文件不假红而就地刷 sha，等于把「已入库」的判据从「内容与导入时一致」降级成「文件被登记过」。
逐条落实：

| 评审意见 | 落实 |
|---|---|
| **A（P1）：manifest 的 sha 语义被「就地改写」带偏** | **本轮最重的地基修复**。manifest 每条拆三列：`imported_sha256`（导入当刻，**永不改写**）/ `current_file_sha256`（盘上现值）/ `imported_content_sha256`（导入当刻**剔除元数据键**后的内容哈希）；旧 `sha256` 键删除。校验器判**三态**：`unchanged`（字节一致）/ `meta_only`（字节变、内容同 → 仍算已入库）/ `changed`（内容也变 → 从严）。迁移脚本 `migrate_manifest_3col.py` 把 8 份 legacy 的 `imported_sha256` 还原成**打标记前**的 sha（`_archive/*.pre-legacy-mark.json` 即导入当刻字节），迁移 49 条 = 41 unchanged + 8 legacy_meta_only。**「刷 sha 就能骗过校验」这条路被堵死** |
| **B（P1）：两个只读巡检用的是可写连接** | `chapter_audit.py` / `coverage_gap.py` / `chapter_pending_map.py` 统一 `file:...?mode=ro`；04 §3.6 写死验收标准「跑完巡检 db 文件 mtime 不变」 |
| **C：覆盖率分子分母没写清** | 04 §3.5 补「分母口径」框：分母 = **上册且有官方骨架的 73 册 / 307 章**（不是全库 146 册 / 618 章）；点名 **27 册无骨架 = 高中 9 学科 × g10–g12**，属另一条任务线，既判不了覆盖也巡检不了占位，是**口径盲区** |
| **D-1：app 端空态** | 练习页裸 `Text('暂无题目')` → `_EmptyPracticeState`（图标 +「本节内容准备中」+ 引导）；单元页/节级空态同步为「本单元/本节内容准备中」 |
