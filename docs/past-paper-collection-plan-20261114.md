# 深圳 1–9 年级期中/期末真题采集计划（2021–2025 学年）

> **文档编号**：采集方案 PA-01（配套 D-10《真题来源检索与录入规范》与 R-07 台账）
> **日期**：2026-11-14　**状态**：检索已完成 · 待授权获取文件后执行结构化录入
> **范围**：深圳市 g1–g9，学科按深圳课程设置，学期覆盖近 5 学年（2021-22、2022-23、2023-24、2024-25、2025-26）的**期中、期末**两场
> **重要前提**：本方案**不包含 AI 生成或拼装的“真题”**。真实卷必须以原始文件（PDF / 扫描件 / 照片）为唯一来源，逐卷登记来源与授权后入库；无文件不建卷。

## 一、检索结论（真实可得性）

### 1.1 公开渠道实测

| 渠道 | 层次 | 实测情况 | 准入结论 |
|---|---|---|---|
| 深圳市教育局 / 各区教育局官网 | L2 官方 | 检索 `site:sz.gov.cn` 只有政策、招生、考试规则与“低年级多元测评”报道；**未公开发布期末学科试卷** | 不可作为题源（无原卷） |
| 21世纪教育网（21cnjy.com） | L3 付费平台 | 有真实成套汇总，如「【广东省各地】2024-2025学年八年级下英语期末试卷汇总」收录 **118** 份，深圳部分含 **南山区 / 罗湖区 / 福田区 / 龙华区 / 龙岗区 / 宝安区 / 光明区 / 深圳中学 / 高级中学** 等 18 份（图片版、扫描版、PDF 版，部分含答案、部分无答案） | 需平台授权或用户已购账号下载原文件；**不得从网页直接抓取重制** |
| 学科网（zxxk.com） | L3 付费平台 | 有「2024-2025学年七年级/八年级下学期期末试卷解析版汇总」按区成套（盐田、宝安、龙华、罗湖…） | 同上 |
| 小学试卷网（szxuexiao.com）等 UGC 站 | L4 未授权转载 | 标题如「深圳南山区2025年六年级数学上学期期末试卷免费下载」 | **黑名单**（来源不明、二次转载、无授权链） |
| 原创力文档 / 百度文库 等 | L4 未授权转载 | 多为“真题复习专题”类二次加工文档，非原卷 | **黑名单**（且常为教辅改编，非原卷） |

### 1.2 关键事实

1. **深圳真题确实存在且成规模**，但载体是**图片/扫描 PDF**，不是可解析文本；一份卷需 OCR + 人工校对才能变成结构化数据。
2. 平台侧多为**付费或积分下载**，且用户协议通常禁止再分发；因此入库前必须拿到「授权说明」（`license_note`）或由用户以自有账号取得文件并确认内部使用范围。
3. **g1–g2 无纸笔期中/期末卷**：按教育部“小学一年级不布置书面家庭作业、不进行纸笔考试”及深圳“低年级多元测评（乐考）”实践，1–2 年级不存在可采集的学科纸笔真题。该学段不设真题目标，改由既有模拟卷与过程性测评覆盖。
4. 同一区同一场次常有“图片版 / 扫描版 / 含答案版”多个版本，**按「一区一场一卷」去重**，优先取含答案且清晰度最高的版本。

## 四、执行 SOP（拿到文件后按此走）

1. **取文件**：用户提供 PDF/图片（自有账号下载或已购资料），放入 `backend/build/past_papers/raw/`，按 `paper_uid` 命名；登记 `file_sha256`。
2. **OCR**：图片/扫描卷走 OCR（保留版面坐标，题干与选项分行）；纯文本 PDF 直接抽取。
3. **结构化**：按 `past_paper_import_template.json` 填写；题干保留原标点与题号，**不得改写题面**（改写即非原卷）。
4. **校验**：`python _validate_past_papers.py <file.json> --strict`，必须 0 error；warning 逐条登记处置。
5. **去重**：同 `paper_uid` 拒绝重复；跨卷题干重合率 ≥30% 判“非原卷/重复卷”，退回。
6. **复核**：录入人 + 复核人双签，`is_past_paper=true`、`status=draft` → 提交复核 → 发布（沿用 D-09 §5.7 审核流）。
7. **台账**：同步 `release/content-compliance/license-ledger.md` 的真题分区（11 列）。

| # | 指标 | 阈值 |
|---|---|---|
