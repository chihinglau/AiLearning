# 深爱学（AiLearning）隐私政策

> **最后更新**：2026-11-06
> **发布版本**：`2026.11.06`（版本号升高须触发 App 端重新征求同意）
> **适用产品**：深爱学（AiLearning）Android 版 / HarmonyOS NEXT 版 App 及配套服务
> **公网地址**：`https://<正式域名>/legal/privacy`（上线后由后端配置下发）

深爱学（AiLearning，以下简称"本应用"或"我们"）是一款面向**深圳市小学、初中、高中学生（6–18 岁）**的跨平台学习辅助应用，提供同步练习、错题本、知识点讲解、单元测/期中/期末测评与学情分析，并为家长提供学习陪伴与时长管理能力。

我们深知未成年人个人信息的高度敏感性，**仅收集实现学习功能所必需的最少信息**，不出售、不用于定向广告，不做与学习无关的采集。本政策说明我们收集哪些信息、为何收集、如何保护，以及您（及未成年人的监护人）如何行使权利。

---

## 1. 我们收集的信息

### 1.1 您主动提供的信息

| 场景 | 信息项 | 是否必需 | 说明 |
|---|---|---|---|
| 注册 / 登录 | 手机号、密码 | 必需 | 手机号用于账号识别与安全验证；密码经加盐哈希后存储，服务端不保存明文 |
| 账号资料 | 昵称 | 可选 | 可留空，默认使用系统生成昵称 |
| 角色与学段 | 角色（学生/家长/教师等）、学段、年级 | 学生必需 | 年级用于匹配深圳本地教材（人教版/粤教版/牛津深圳版等）与测评范围 |
| 家庭绑定 | 家长与孩子的绑定关系、确认时间 | 儿童账号必需 | 由家长发起、孩子或监护人确认后生效（`consent_at` 留痕） |
| 家长管控 | 每日使用时长上限 | 可选 | 家长为孩子设置，用于学习时长管理 |
| 组织信息（规划中） | 学校、班级、任教学科 | 教师/校管必需 | 仅用于班级学情与作业管理，不对学生展示 |

### 1.2 学习过程中产生的信息

- **教材绑定**：所选教材、学期、绑定状态；
- **答题与练习记录**：题目、您的作答、是否正确、作答耗时、错因标注；
- **学情数据**：知识点掌握度、错题本条目、复习计划与复习结果；
- **测评记录**：单元测/期中/期末/模拟考的作答、得分与报告；
- **学习行为摘要**：学习时长、连续学习天数等统计值（用于生成学情报告）。

> 上述数据仅用于向您（及已授权的家长/教师）展示学情、生成练习推荐与错题复习计划。

### 1.3 设备与日志信息

- 设备型号、操作系统版本、App 版本号、崩溃日志摘要——用于兼容性适配与故障排查；
- IP 地址与操作日志——仅在安全审计与异常登录识别时记录（见§6）。

### 1.4 我们**不收集**的信息

当前版本**不申请**以下权限，也不采集对应信息：

- 精确/粗略地理位置；
- 通讯录、通话记录、短信；
- 相机、麦克风、相册（后续若上线语音跟读评测，将在启用前单独弹窗告知并征得同意，本政策同步更新）；
- 身份证号、人脸、指纹等生物识别信息；
- 与学习无关的设备应用列表。

当前 App 仅申请网络访问权限（Android `INTERNET` / HarmonyOS `ohos.permission.INTERNET`）。

## 2. 我们如何使用信息

我们仅在下列目的与法律基础上处理信息（《个人信息保护法》第十三条）：

| 目的 | 处理的信息 | 法律基础 |
|---|---|---|
| 提供账号注册、登录与身份识别 | 手机号、密码哈希、角色 | 订立与履行服务合同所必需 |
| 匹配深圳本地教材、生成学习路径 | 学段、年级、教材绑定 | 履行服务合同所必需 |
| 判题、错题本、掌握度与学情报告 | 答题记录、错题、掌握度 | 履行服务合同所必需 |
| 组卷与测评（单元测/期中/期末） | 测评作答与得分 | 履行服务合同所必需 |
| 家长查看孩子学情、设置时长 | 绑定关系、学情摘要、时长上限 | 监护人同意 + 履行服务合同所必需 |
| 班级学情与作业（教师/校管，规划中） | 班级成员、学科、学情聚合 | 学校授权 + 监护人同意 |
| 安全风控与合规审计 | IP、操作日志 | 履行法定义务、保障服务安全 |
| 稳定性改进 | 崩溃日志摘要 | 您的同意（可在设置中关闭） |

**我们不会**：

- 将您的学习数据用于广告定向投放或出售给任何第三方；
- 使用未成年人的学习数据做与教育服务无关的商业分析；
- 在未经监护人同意的情况下，向儿童账号提供社交、公开分享或付费功能。

## 3. 未成年人个人信息特别保护

本应用主要用户为未成年人，我们按《个人信息保护法》《未成年人保护法》《儿童个人信息网络保护规定》执行以下规则：

### 3.1 分区保护

| 年龄段 | 规则 |
|---|---|
| 不满 14 周岁（儿童） | 注册与使用须取得**监护人明确同意**；账号标记为儿童账号（`is_child`），至少绑定 1 名状态为 `active` 的家长/监护人且 `consent_at` 非空，方可完整使用；未取得同意时仅提供受限的浏览体验 |
| 14–18 周岁 | 需监护人同意或指导；家长可绑定并查看学情、设置使用时长 |
| 成年用户（家长/教师等） | 按一般规则处理 |

### 3.2 家长绑定与确认

- 绑定流程：家长发起 → 孩子或监护人确认 → 状态 `active`；任一方可随时解除（`revoked`）。
- 未生效（`pending`）或已解除（`revoked`）的绑定，家长**不能**读取孩子任何学情数据。
- 家长可查看孩子年级、学情、错题与报告，但**不可**查看孩子与同伴的排名对比；家长不能直接修改孩子的年级（需孩子确认或校管修正）。

### 3.3 最小化与限制

- 儿童账号默认关闭社交、公开分享、排行榜展示与付费入口；
- 不向未成年人推送营销信息；如需推送学习提醒，须经监护人同意且可一键关闭；
- 家长可设置每日使用时长上限，到达上限后限制继续答题。

### 3.4 监护人权利

监护人可代表未成年人行使本政策第 8 条全部权利，并可要求我们删除儿童的相关信息。我们发现自己在未取得监护人同意的情况下收集了儿童个人信息，将尽快删除。

## 4. 信息共享、委托处理与转让

- **不出售**：我们不会出售、出租您的个人信息。
- **不对外共享**：除以下情形，不向第三方共享：
  1. 已取得您或监护人的单独同意；
  2. 依据法律法规或有权机关依法定程序的要求；
  3. 为提供云服务所必需，委托云服务商作为**受托方**存储数据（受托方仅按我们的指示处理，不得自行使用）。
- **学校场景（规划中）**：教师/校管仅能查看其授权范围内的班级学情；跨校数据严格隔离。
- **转让**：如发生合并、分立、收购等，我们将告知接收方信息并继续受本政策约束；接收方变更原处理目的须重新取得同意。

**数据存储地**：中国大陆境内；当前不涉及个人信息出境。

## 6. 存储、安全与留存期限

### 6.1 安全措施

- 全站 HTTPS/TLS 传输加密；
- 密码加盐哈希存储；登录凭证（Token）存放于 App 私有存储；
- 数据库按最小权限访问，敏感操作（改角色、改年级、查看他人学情、导出）**100% 写入审计日志**（操作人、动作、时间、IP）；
- 越权访问一律拒绝并留痕（如学生读取他人学情返回 `SCOPE_DENIED`）。

### 6.2 留存期限

| 数据类别 | 留存期限 |
|---|---|
| 账号与资料 | 服务存续期间；注销后删除或匿名化 |
| 学习与测评记录、错题与掌握度 | 保留至账号注销；用于跨学期学习档案延续（可申请提前删除） |
| 家长绑定关系与同意记录 | 绑定解除后保留必要期限以证明合规（不超过 3 年） |
| 安全审计日志（含 IP） | 不少于 6 个月，不超过 2 年（满足网络安全法留存要求） |
| 崩溃日志 | 180 天 |

超出期限后，我们将删除或做不可逆匿名化处理。

### 6.3 账号注销

- App 内提供「设置 → 账号与安全 → 注销账号」入口；
- 注销申请受理后 **15 个工作日内**完成删除或匿名化（法律法规另有要求保留的除外），并同步解除家长绑定；
- 注销后不可恢复，历史学情将一并删除，请提前通过"数据导出"留存。

## 7. 您的权利

| 权利 | 行使方式 |
|---|---|
| 查询 / 访问 | App 内「我的」查看账号、年级、教材绑定与学情；或联系客服 |
| 更正 | 在 App 内修改昵称、选科；年级变更按学期频率限制（每学期 1 次）并在操作前提示影响 |
| 复制 / 导出 | 通过「数据导出」获取个人学习数据副本（规划中，上线前以页面为准） |
| 删除 | 删除单条错题/记录；注销账号删除全部数据 |
| 撤回同意 | 在系统设置中关闭可选权限；撤回后停止基于该同意的处理，但不影响撤回前已进行的处理 |
| 解释说明 | 可要求我们说明个人信息处理规则 |

未成年人上述权利由监护人代为行使。我们将在收到请求并验证身份后 **15 个工作日内**答复。
